## Le jeu en 30 secondes

Un **TCG tour-par-tour** à 30 PV, deck de 40 cartes, mélangeable entre **3 univers**
(Bloodborne, JoJo, WTF). Mana qui se convertit en **Cristaux**, mécanique secondaire
d'**Extase** alimentée par les dégâts, plateau à 2 lignes, **5 types de cartes**, mode
**Classé** sur l'**Échelle Cosmique** (Poussière Stellaire → Singularité).

<table>
<tr>
<td width="33%" valign="top">

### Collection vivante

**181 cartes**, 4 raretés, 3 statuts. Drop pondéré dans les packs, decraft des doublons,
achat ciblé en fragments.

</td>
<td width="33%" valign="top">

### Aucun paiement requis

Aucun achat in-app, aucun contenu derrière un paywall. Tout débloqué via la
progression in-game.

</td>
<td width="33%" valign="top">

### Multijoueur immédiat

Matchmaking, lobbies privés, IA d'entraînement, mode Classé. Compte gratuit, sans inscription requise pour essayer.

</td>
</tr>
</table>
