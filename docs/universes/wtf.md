# Univers — WTF

## Présentation

Cartes meme, références internet, chaos assumé. Le plus petit catalogue (16 cartes) mais le plus impactant à l'unité : chaque carte WTF est une situation absurde ou une bombe stratégique.

WTF n'est pas conçu pour un deck mono — c'est un **complément** qui casse le sérieux d'un deck principal. Quelques exceptions notables (Floppa chain) permettent un build pur WTF.

## Mécaniques signature

- **Effets de chaîne unique** — *Sur les traces de Floppa* + chaîne Floppa (Mage → Guerrier → Assassin → Divinité).
- **Délai dévastateur** — *Floppa : Divinité* fait 100 dégâts à l'adversaire après 2 tours. Le deck entier tourne autour de la protéger.
- **Forced draw** — *GitGud* force le match nul. Carte troll par excellence.
- **Compteurs spécifiques** — Ricardo scale avec le compteur *WtfCardsPlayedCount*.
- **Espion** — Vibecoder bascule chez l'adversaire à l'épuisement de son compteur.

## Archétypes

### Floppa chain

**Concept** : *Sur les traces de Floppa* ajoute toutes les cartes Floppa au deck, on enchaîne les transformations jusqu'à *Floppa : Divinité*.

- Pivots : *Sur les traces de Floppa* (Sort, 1 mana), Floppa Mage, Floppa Guerrier, Floppa Assassin.
- Finisher : Floppa Divinité (Délai 2 → 100 dégâts).
- Stratégie : protéger Floppa Divinité (Provocation, Esquive, Anti-Magie via cross-univers Bloodborne) pendant 2 tours.

### Cherry-pick chaos

**Concept** : 1-4 cartes WTF intégrées dans un deck Bloodborne ou JoJo pour avoir un trick imprévisible.

- Candidats : *Monster* (1 mana, permet à une unité d'attaquer immédiatement), *GitGud* (sortie de secours), *Are you winning son* (effet de meme).

### Troll pur

**Concept** : pas un deck compétitif, un deck pour faire rire la communauté.

- Maximum de WTF compatibles, finition par *GitGud* ou *Floppa : Divinité*, peu importe l'efficacité.
- Le but : la story Discord post-partie.

## Note d'usage

WTF est pensé pour être **fun avant tout**. Si tu cherches du compétitif strict, Bloodborne et JoJo offrent plus de profondeur. Si tu cherches à raconter une partie qui restera dans l'historique du Discord, c'est ici.

## Lore Omnicard

> Pas de lore — c'est WTF. C'est l'univers qui ne se prend pas au sérieux et qui rappelle que le jeu est avant tout un terrain de jeu.

Les propositions de cartes WTF sont bienvenues, particulièrement celles qui détournent intelligemment les mécaniques existantes.
