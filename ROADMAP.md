## 🌌 Long terme — pistes ouvertes

| Idée | Description |
|---|---|
| 🎲 **Mode draft / sealed** | Construction de deck à la volée à partir de packs ouverts. |
| 🏟️ **Tournois communautaires** | Format intégré, brackets, récompenses cosmétiques. |
| 🤖 **Bot Discord** | Tirage de cartes, lookup, simulation de combo. |
| 📖 **Lore écrit** | Background narratif pour chaque univers. |
| 🔨 **Builder hors connexion** | Construction de deck en consultation + brouillons. |
| 🌍 **Internationalisation** | Anglais probablement en premier, selon la demande communautaire. |

## 💬 Comment influencer la roadmap

Les propositions et votes se passent :

- Sur le **[Discord](https://discord.gg/XBY9FPNv9g)** — forum `Suggestions`.
- Sur les **GitHub Discussions** de ce dépôt — catégorie `Idées de cartes` ou `Discussion générale`.

Toute proposition argumentée est lue, même les WTF.
