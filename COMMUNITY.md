# Communauté et contribution

## Rejoindre

- **Discord** : [discord.gg/XBY9FPNv9g](https://discord.gg/XBY9FPNv9g) — le lieu principal pour discuter, proposer des cartes, signaler des bugs, organiser des parties.
- **GitHub Discussions** : onglet `Discussions` de ce dépôt — espace plus structuré pour les propositions et les questions de fond, complémentaire au chat Discord.

## Contribuer

### Proposer une carte

Format conseillé (à poster sur le Discord, salon `Suggestions`, tag `Carte`, ou sur GitHub Discussions catégorie `Idées de cartes`) :

- **Nom** : ...
- **Univers** : Bloodborne / JoJo / WTF / autre
- **Type** : Unité / Sort / Gear / Piège / Terrain
- **Coût en mana** : ...
- **Stats** (si Unité) : Attaque / PV
- **Effet** : description claire
- **Idée d'art** : référence, mood, scène, personnage source

Une idée par proposition. Si tu en as plusieurs, fais plusieurs posts.

### Signaler un bug

Via les **GitHub Issues** de ce dépôt avec le template `Bug`, ou le Discord avec le tag `Bug`.

### Poser une question sur une règle

Via les **GitHub Discussions**, catégorie `Questions règles`. La réponse marquée comme officielle finira dans la FAQ.

### Proposer un nouvel univers

À discuter en amont sur le Discord. Un univers ajouté doit :

- avoir une cohérence (5 types de cartes minimum jouables) ;
- être proposé par quelqu'un prêt à aider à la conception ;
- respecter les contraintes du projet (fan-content non commercial, voir [LEGAL.md](./LEGAL.md)).

## Code de conduite

Le Discord, les Issues et les Discussions sont des espaces de jeu et de création. On y est respectueux, on évite les sujets clivants sans rapport avec le jeu. Le tag WTF n'est pas un passe-droit pour la toxicité.

Pour la version formelle : voir [`legal/charte-de-conduite.md`](./legal/charte-de-conduite.md).

## Reconnaissance des contributeurs

Les contributeurs réguliers (cartes intégrées au jeu, bugs critiques signalés, traductions, illustrations) sont mentionnés dans le [`CHANGELOG.md`](./CHANGELOG.md) à chaque release pertinente. Une page `CONTRIBUTORS.md` sera ajoutée quand plusieurs contributeurs nommés acceptent d'y figurer.
